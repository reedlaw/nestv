# Licenses

No license has yet been selected for original nestv material. Until the
copyright holders choose one, that material is not offered under an
open-source license.

Third-party components retain their upstream licenses. `make bootstrap`
downloads the license accompanying the pinned `yc_out.sv` revision to
`build/upstream/COPYING`; the encoder's own header identifies it as
GPL-2.0-or-later. See `THIRD_PARTY.md` for the source, immutable revision, and
usage of every pinned dependency.
